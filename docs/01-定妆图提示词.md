## 四、主提示词 v4（留档：重做定妆图时用）

```text
【我上传了两张图，分工必须看清】
第一张：Q版原角色立绘 —— 这是**人物长相、人物比例、画风**的唯一标准。
第二张：红色连体工装的照片 —— 这张**只用来参考服装**。

【第二张图只取服装，下面这些一律不要参考】
不要参考第二张图的成年人身材比例、不要参考它的写实厚涂画风、不要参考它的深色复杂背景、
不要参考它的坐姿与椅子、不要参考它手里的笔记本电脑、不要把它背景里的任何文字或代码放到画面里。

【第一优先：人物比例必须和第一张图一模一样，这一条压倒其他所有要求】
第一张图是**超变形Q版**，整个人的高度只有大约两个头：
- 从头顶（含蓬松头发）到下巴的距离 ≈ 全身高度的 1/2，也就是说**画面上半部分只有头**；
- 从下巴到脚底 ≈ 另外 1/2；
- 头发非常蓬松，最宽处的宽度 ≈ 全身高度的 60%，**比整个身体还宽**；
- 脖子几乎看不见，头直接坐在肩上；肩膀窄而圆；躯干短；腿极短、脚很小；
- 眼睛极大，占脸的一半以上。
**画完后请自检**：把画面从上到下分成两半，上半部分应当只有头部；如果腿的长度超过了头的高度，说明比例画错了，请重画。
在"服装细节"和"比例"之间如果要取舍，**永远优先保住比例**。

【必须保持不变，一项都不许动】
五官、脸型、瞳色、眼型、蓝色长卷发（长度、卷度、发丝走向）、头顶翘起的那撮呆毛、
鲸鱼鳍形状的耳朵、身后那条鲸鱼尾巴、上面写明的Q版比例、粗描边 + 扁平赛璐璐平涂的画风与笔触。

**头发上不要蕾丝发箍、不要蝴蝶结、不要缎带、不要任何发饰**（只保留那撮呆毛）。

【换成这套服装：亮红色连体工装（照着第二张图的款式画，用Q版简化的画法）】
主体：一件亮红色连体工装，从肩到脚连成一体（不是套装、不是卫衣）。
前中：正中间一条深灰色拉链从领口一直拉到腰部。
领子：小立领，领口微开，露出里面一点白色内搭。
胸口：左右各一个带深灰拉链的胸袋。
肩部：两侧深灰色肩带。
腿部：大腿两侧各一块深灰色方形贴片，裤脚收进靴子里。
徽章：左臂一枚方形臂章 —— 白边、红底、中间一枚**纯白色几何图形**，
```

## 六、⚠ 臂章上的「红队」二字：留个底，将来要改就改这里

**问题**：桌宠播放 `东张西望` 和移动类动画时会**整体镜像翻转**（面朝左/朝右切换）。
衣服上的字是画在**素材像素里**的，一翻转就变反字。dsh-pet 的 `noMirror` 只能按**动画分类**屏蔽，
而衣服上的字出现在**所有**动画里 —— 插件层修不了。

当前 v4 采用的是 **A 案：徽章不放字**。若将来想要「红队」二字，把提示词里徽章那句改成
`白边红底，中间是白色汉字「红队」`，并把负面词里的 `汉字` 去掉即可，代价是转身时字会反。

## 七、关于键盘的取舍（为什么保留）

- **保留**（当前决定）：黑客桌宠手里常驻一块全息键盘，风格统一、辨识度高，且已经实测抠像干净。
- **代价**：106 段里有不少"手要动"的动作（挥手、吃东西、抱头、玩魔方…）。
  v4 的定妆图手里有键盘，那几段可能会保留键盘或出现"拿着键盘挥手"的怪姿势 ——
  属于观感瑕疵，不影响能不能用。原始提示词本身是给"空手"角色写的，所以模型多数情况下会照着姿势描述走。
- **敲键盘的那 4 段**（`原地敲击桌面互动`、`写代码`、两段 `碎碎念`）本来写的就是"身前**虚拟键盘**"，
  和 v4 手里的全息键盘天然一致，这几段会最自然。

## 八、设计说明（保留的元素为什么留）

- **亮红色连体工装**：你指定的服装。红色在深色页面背景上非常跳，做桌宠辨识度最高；
  连体工装的整块红面在抠像后轮廓也干净（不像女仆裙那样一堆碎边）。
- **深灰拉链 / 肩带 / 贴片**：把整块红切开，避免在 Q 版尺寸下糊成一片红。
- **左臂徽章**：你那张参考图的臂章就在左臂，位置照搬。
- **黑框方眼镜 + 额上护目镜**：你参考图里的标志性元素 + 赛博感。
- **悬浮全息键盘 + 腰侧全息身份牌 + 发光鞋底**：v3/v4 实测抠像后能保住，
  是"赛博红队"这层味道的主要来源，也正好接上 `写代码`、`原地敲击桌面互动` 这些动画。
- **鲸鱼鳍耳和尾巴保留**：身体特征不是衣服 —— `用鲸鱼尾巴拍打地面`、`鲸鱼吐泡泡特效`、
  `蓝鲸现世` 三段才继续成立。

## 九、这套提示词的方法论（将来自己改时照抄）

1. **比例给数字 + 开头给 + 中途自检 + 结尾复述**。v1 是数值写错（"三头身"），v2 是被服装细节稀释（2.73），
   v3 起用三重压制才稳定拿到 2.00 / 1.94。
2. **多图参考必须写明分工**。只说"参考这两张"，模型会把成人比例、写实画风、背景文字一起抄进来。
3. **服装参考图要先裁干净**。`out/style-ref/红队工装参考.png` 已切掉标题文字和水印。
4. **改完一定要量**：`measure-proportion.mjs` 判定行 + `side-by-side.mjs` 并排图，两分钟出结论；
   转码后再看 `keyscreen.mjs` 报的**绿边百分比**（>0.5% 就要调 `--similarity`）。
